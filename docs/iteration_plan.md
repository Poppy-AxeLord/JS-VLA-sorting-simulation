# 迭代优化路线图 —— 工业分拣 VLA 仿真 POC

> 文档定位：本文基于 v1→v2→v3 已验证的提升数据，规划下一步迭代（多视角融合 / 模糊指令优化 / 世界模型增强等），按"高影响低成本"排优先级，给出预期收益与里程碑。对应失败归因方法论见 `failure_analysis.md`，指标依据见 `metrics_system.md`。

---

## 一、回顾：v1→v2→v3 已验证了什么

我们已经用三个真实评测版本（看板预置种子数据，各跑全部 30 个任务）跑通了"失败归因 → 针对性优化 → 成功率提升"的完整闭环：

| 版本 | 配置 | 总成功率 | 关键改动 | 由哪类失败分析驱动 |
|---|---|---|---|---|
| **v1** | rule_based + baseline 策略 | ≈ 0.62 | 跑通基线，建立失败分布基准 | —（基线，建立观测） |
| **v2** | rule_based + optimized 策略 | ≈ 0.74 | 优化置信度阈值 / 重试 / 异常恢复 | 执行类失败 + 重试/恢复指标偏低 |
| **v3** | optimized 策略 + world_model | ≈ 0.83 | 抓取前风险预判，调整姿态/顺序 | 执行类"放置掉落"集中在易碎大件 |

**关键结论**：v1→v2（+12pct）证明"策略容错"有效；v2→v3（+9pct）证明"世界模型风险预判"有效。两步都是先看失败分布、再下针对性药、最后重测验证涨幅——**这条方法论本身已被验证可复用**，下一步只需继续沿着失败分布最高的环节推进。

**当前瓶颈定位（v3 之后的失败分布）**：成功率虽到 0.83，但困难难度仍被两类失败拖累——
- **感知类失败（≈40%，遮挡看不见占 22%）**：单俯视相机的结构性盲区，是当前最大短板。
- **理解类失败（≈15%，模糊指令歧义）**：rule_based 对"大左小右"等相对约束解析仍不稳。

## 二、下一步迭代候选与优先级排序

我们用 **影响（impact）× 成本（cost）** 二维矩阵给候选项排序，遵循"高影响低成本优先"原则。

```
高影响 │  ★v4 多视角融合          ★v3 世界模型(已做)
       │  (中成本,主攻感知)        
       │                          ★v5 模糊指令优化
       │                          (低成本,主攻理解)
       │  ─────────────────────────────────────
低影响 │            v6 Sim2Real(远期,高成本)
       │
       └──────────────────────────────────────
         高成本                          低成本
```

### 优先级排序结论

| 优先级 | 迭代项 | 主攻失败类型 | 预期收益 | 影响 | 成本 |
|---|---|---|---|---|---|
| **P0** | v5 模糊指令优化 | 理解类（歧义处理） | 误拣率 -3pct，总成功率 +2~3pct | 中 | **低** |
| **P0** | v4 多视角融合 | 感知类（遮挡看不见） | 困难难度成功率 +6~8pct | **高** | 中 |
| P1 | v3+ 世界模型增强 | 执行类（残余掉落） | 易碎件抓取成功率 +3~5pct | 中 | 低 |
| P2 | v6 Sim2Real + 真实模型 | 全局（缩小仿真现实差） | 提升可信度（非直接涨分） | 高 | **高** |

> 排序逻辑：**先做模糊指令优化（最低成本先摘）和多视角融合（最高影响先攻）这两个 P0**。模糊指令优化几乎只改 `rule_based` 解析逻辑，零新增依赖、当天可验证；多视角融合虽中成本，但直击占比最高（40%）的感知失败，影响最大。世界模型增强收益递减、放 P1；Sim2Real 成本高且属"提升可信度"而非"直接涨分"，放远期 P2。

## 三、各迭代项详细规划

### v4 —— 多视角融合（P0，主攻感知类失败）

- **问题**：单俯视相机有结构性遮挡盲区，困难难度感知失败占 40%、其中遮挡 22%，直接推高漏拣率。
- **方案**：启用侧视相机（接口已在 `camera.py` / `SortingEnv.get_camera_image(view="side")` 预留），俯视 + 侧视融合，消除单视角盲区；感知失败注入模型相应下调遮挡惩罚。
- **预期收益**：困难难度任务成功率 +6~8pct，识别准确率 `recognition_accuracy` +3~5pct，漏拣率下降。
- **验证方式**：重跑 benchmark（困难子集），看感知类失败占比是否从 40% 降到 25% 以下、漏拣率是否下降。
- **里程碑**：M1 完成侧视渲染与融合逻辑；M2 重测困难难度并确认感知失败占比下降；M3 全难度回归确认北极星不回退。

### v5 —— 模糊指令优化（P0，主攻理解类失败）

- **问题**：理解类失败 15%，集中在"大左小右""把大的放左边小的放右边"等相对/模糊约束，歧义处理失败导致误拣。
- **方案**：强化 `rule_based.py` 的模糊语义解析——显式建模"相对大小→空间映射"规则，结合 SceneState 真值做相对排序后再分配料盒；解析失败时降置信度触发人工介入兜底而非硬猜。
- **预期收益**：误拣率 `mis_pick_rate` -3pct，理解类失败占比减半，模糊型任务成功率显著提升。
- **验证方式**：重跑 benchmark 的"模糊分拣"任务子集，看理解类失败是否下降、误拣率是否改善。
- **里程碑**：M1 实现相对约束解析；M2 模糊任务子集回归；M3 确认无新增理解失败回归。

### v3+ —— 世界模型增强（P1）

- **问题**：v3 已用世界模型把执行失败压下一截，但易碎大件仍有残余"放置掉落"。
- **方案**：在 `simple_predictor.py` 基础上细化启发式——按材质（玻璃/复合）和重心进一步分级风险，对高风险件追加"降速放置 + 二次确认"；`simulate_rollout` 提前预测整条 plan 的风险点并重排顺序。
- **预期收益**：易碎件 `grasp_success_rate` +3~5pct，碰撞次数进一步下降。
- **里程碑**：M1 风险分级细化；M2 A/B 对比（增强 on/off）确认增益；M3 并入主版本。

### v6 —— Sim2Real + 真实模型（P2，远期）

- **问题**：当前为仿真 + 失败注入，存在 Sim2Real Gap；真实落地需真实感知与真实 VLA。
- **方案**：接入 SmolVLA-500M 真实推理（torch+transformers+MPS，加载失败仍自动回退 rule_based，零风险）；接真实相机数据做仿真物理参数校准；失败注入模型逐步被真实失败信号替换。
- **预期收益**：不直接涨分，但大幅提升结论可信度，把"产品验证"推进到"产线试点"。
- **里程碑**：M1 SmolVLA 真实推理跑通（MPS）；M2 真实相机数据接入；M3 Sim2Real 校准与试点评估。

## 四、整体路线图与里程碑甘特

```
阶段        迭代项              主攻          预期总成功率    优先级
─────────────────────────────────────────────────────────────────
已交付   v1 基线              建立基准         ≈0.62          —
已交付   v2 策略优化          执行/容错        ≈0.74          —
已交付   v3 世界模型          执行/易碎件      ≈0.83          —
─────────────────────────────────────────────────────────────────
下一冲刺  v5 模糊指令优化      理解             ≈0.85          P0(低成本先摘)
下一冲刺  v4 多视角融合        感知             ≈0.88~0.90     P0(高影响先攻)
其后      v3+ 世界模型增强     执行残余         ≈0.90+         P1
远期      v6 Sim2Real+真实模型 全局可信度        —(提质不提分)  P2
```

> 节奏建议：v5 和 v4 并行启动（v5 改解析、v4 改感知，互不冲突），一个冲刺内可同时验证。两项落地后总成功率有望从 0.83 推进到 0.88~0.90，把困难难度这块最硬的骨头啃下大半。

## 五、迭代方法论总结（可复用的"涨分"配方）

1. **永远从失败分布最高的环节下手。** 当前是感知（40%）和理解（15%），所以 P0 是 v4 和 v5。
2. **高影响低成本优先。** 先摘低垂果实（v5 改规则零依赖），再攻最大影响（v4 多视角）。
3. **每项迭代都绑定一个可验证的预期收益。** "+6~8pct""误拣率 -3pct"——不能验证的优化不排期。
4. **改完必重测，用北极星裁决，用失败分布归因。** 涨了且对应失败占比降了才算成功；没涨就回到失败分析重新归因。
5. **降级机制保证迭代零风险。** 即使 v6 接真实模型失败，也自动回退 rule_based，演示永不崩——这让我们敢于激进迭代。

> 一句话：**这份路线图不是"我想做什么"，而是"数据告诉我该做什么、按什么顺序做、做完预期涨多少"。** 它把产品迭代从"凭感觉排需求"升级成了"用失败归因和 ROI 排优先级"的可证伪工程。
